### 📐 MULTI DEVICE LAYOUT
Media Query를 사용하여 1920 / 1024 / 640px 각 해상도에 최적화된 레이아웃을 구성하였습니다.
* PC 1920px : 풀스크린 영상 비주얼, 와이드 레이아웃
* TABLET 1024px : 영상 비주얼 유지, 콘텐츠 2열 재배치 및 스와이프 적용
* MOBILE 640px : 비주얼을 이미지로 교체, 햄버거 메뉴, 일부 이미지·카드 숨김으로 핵심 콘텐츠 위주 구성


### ⚠️ 웹 표준 / 웹 접근성
* W3C 마크업 검사(HTML5) 및 CSS 검사(CSS3) 통과
* 웹 접근성 자동점검(K-WAH) 전 항목 준수율 100%
* 시맨틱 마크업, 아웃라인 정돈
* img tag(alt), a tag(title) 등 태그 속성을 활용해 접근성 향상


### 🖥️ UIUX
1. 히어로 영역에 풀스크린 영상을 배치해 텍스트 없이 이미지 중심의 강렬한 첫인상 연출
2. 섹션 배경을 밝음/어두움으로 교차 배치하고 섹션 번호(01~05)로 콘텐츠 흐름을 명확히 구분
3. OVERVIEW : 대표 이미지와 보조 이미지를 기준선에 맞춰 배치해 기기 콘셉트 소개
4. FEATURES : PS5, 무선 헤드셋, 무선 컨트롤러, 리모트 플레이어 라인업을 엇갈림 카드로 배치하고 한 줄 특징 표기
5. REMOTE PLAY : TV · 태블릿 · 모바일 기기 이미지를 나란히 배치해 어디서나 이어지는 플레이를 시각화
6. GAMES : 게임 커버 카드 슬라이더(Swiper)와 선택 게임 정보(장르, 출시일, 플랫폼)를 함께 제공
7. GALLERY : CSS Grid로 크기가 다른 이미지 타일을 조합해 역동적인 갤러리 구성
8. SCROLL DOWN · TOP 버튼을 PlayStation 기호(○ × △ □) 콘셉트로 디자인하고 jQuery로 부드러운 스크롤 구현
9. 해상도별로 이미지·텍스트를 단계적으로 축소/제거해 모든 기기에서 가독성 유지
